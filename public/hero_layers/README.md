# Hero layered parallax assets

Place transparent PNGs here for the premium diorama. All layers must share the **same dimensions and anchor point** so they align when stacked.

| File | Description |
|------|-------------|
| `sky.png` | Clouds only |
| `shell.png` | Outer concrete frame / perimeter |
| `left_zone.png` | Left wall + volumes |
| `center_zone.png` | Center block structure |
| `right_zone.png` | Right wall + shelving |
| `floor_foreground.png` | Pads + furniture foreground |

If any file is missing, the hero falls back to the single JPG (`/leo-may-interactive-website-background.jpg`).
