# Ambient music

The app loads **`beta-drift-demo-v1.mp3`** from this folder (`/audio/beta-drift-demo-v1.mp3`).

If the file is missing after clone, copy your track here as `beta-drift-demo-v1.mp3` (e.g. from “Beta Drift Demo v1.mp3” in Downloads).

The previous track **`As We Are.mp3`** remains in `public/` root for optional future use; it is not referenced by the app.
